# Data and attribution notes

- Base vector map data: OpenStreetMap contributors, distributed/rendered through OpenFreeMap / OpenMapTiles. Keep the in-app attribution control visible.
- OSM data is subject to the Open Database License (ODbL); consult the current OpenStreetMap copyright/attribution guidance before redistributing derived databases.
- Leuphana site-plan and factsheet material is used as factual research/reference only. No Leuphana photographs or copyrighted plan artwork is bundled into the app.
- Aerial mode streams the official LGLN DOP20 WMS at runtime; imagery is not redistributed in this repository. LGLN open geodata is used with visible source attribution (`© GeoBasis-DE/LGLN 2026`) in accordance with the provider attribution requirements.
