# Campus geometry sources

The 3D campus is an original geometric interpretation; the copyrighted Leuphana campus-plan raster is **not** shipped as a map texture.

## Primary visual reference

- Leuphana Universität Lüneburg, **Lageplan Zentraler Campus**
- Official page: https://www.leuphana.de/universitaet/lageplaene.html
- Address: Universitätsallee 1, 21335 Lüneburg
- Central Building architecture: https://www.leuphana.de/universitaet/campus/zentralgebaeude/architektur.html
- Official Central Building factsheet: https://www.leuphana.de/fileadmin/user_upload/universitaet/files/1804_02_ZG_FACT_SHEET_a4_final.pdf
- The user supplied an official campus-plan image as a development reference.

## Geospatial anchor validation

Open geographic coordinates were used only to validate orientation/scale and anchor major objects. The project keeps attribution to **© OpenStreetMap contributors** where these anchors are referenced. The affine calibration uses Mensa, Universitätsbibliothek and Zentralgebäude. Additional lecture-hall / Hörsaalkomplex points are secondary plausibility checks, not survey control points.

## Precision statement

- Positions and footprints: reconstructed from the campus plan and aligned by an affine plan→metre calibration.
- Mensa, Library and Central Building: calibration anchors; lecture-hall points: secondary plausibility checks.
- Remaining footprints: plan approximations, not survey data.
- Central Building maximum height: 36.75 m is published in the official Leuphana factsheet.
- Other building heights: intentionally approximate visualization values. They must not be interpreted as survey-grade dimensions.

See `CAMPUS_MAPPING.md` for the building-by-building mapping notes.
